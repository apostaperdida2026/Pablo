Conceito Básico

Entenda a Manipulação de Algoritmos

Quando interagimos com um sistema digital fechado, nem sempre os resultados dependem da sorte. Programadores podem definir regras para que o robô vença de forma previsível.

💡 O que este projeto mostra?

Usamos o clássico Par ou Ímpar para demonstrar como um sistema pode ler a sua jogada e alterar a dele no mesmo instante para definir o resultado.

Lógica Simplificada

Veja abaixo como o robô toma decisões no código:

se (suaEscolha == "ÍMPAR") {
  roboGanhaCom = "PAR";
} senao {
  roboGanhaCom = "ÍMPAR";
}

Em um sistema manipulado, a regra intercepta a sua escolha antes de calcular a resposta final.
